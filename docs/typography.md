# Типографіка Italiano

Оновлення 18.10.2026. Спільна гарнітура — Inter Variable, включена в збірку
через @fontsource-variable/inter. Кирилиця й латинка використовують одну родину;
нормальний і справжній курсивний стилі мають локальні WOFF2-файли. Unicode-range
дає браузеру завантажувати потрібні набори. Моноширинний шрифт залишений лише
для редакторського JSON. Різні декоративні serif-гарнітури з текстових елементів
прибрані.

Джерело розмірів і насиченостей: `src/styles/typography.css`, підключене перед
компонентними стилями. Наявні стилі всіх семи файлів переведені на ролі через
CSS-змінні; не додано каскаду !important поверх попередніх розмірів. Числові
насиченості узгоджені як 400/500/600/700. Для звичайного тексту немає залежності
розміру від vw; адаптація задається один раз через роль.

| Роль | Desktop | ≤600 CSS px |
| --- | --- | --- |
| Назва сторінки `--text-page` | 32 | 28 |
| Назва секції `--text-section` | 24 | 22 |
| Назва картки `--text-card` | 18 | 18 |
| Умова вправи `--text-task` | 28 | 24 |
| Основний текст / відповіді / введення `--text-body` | 16 | 16 |
| Кнопка `--text-control` | 16 | 16 |
| Другорядний текст `--text-meta` | 14 | 14 |
| Коротка мітка `--text-caption` | 12 | 12 |
| Текст читання `--text-reading` | 22 | 20 |
| Навігація `--text-nav` | 14 | 12 |

Інтервали: звичайний текст 1.55, заголовки 1.3, читання 1.8. Підкреслені слова
в тексті читання успадковують його кегль й не виглядають окремими маленькими
кнопками. Назва статті читання використовує роль секції, питання — роль умови.
Одне слово у тренуванні залишається окремою крупною роллю 32–48 px. Статистика
має звичайну та компактну ролі, щоб числа в невеликих кільцях не переповнювались.

Винятки — іконки, логотип, декоративні літерні знаки й номери клітинок кросворда;
їхній кегль не є кеглем абзацу. Значення font-size:0, які приховують напис кнопки
зі збереженим aria-label на телефоні, збережені. Стандартне введення має 16 px;
ігрові літери та код кімнати мають свої ролі.

Після збільшення навігації мобільний ряд переведений із жорстких шести колонок
на flex із природною шириною назв. На вузькому екрані він прокручується, не
стискаючи й не накладаючи тексти. На 390 CSS px усі назви поміщаються в ряд.

## Перевірка

Production build TypeScript/Vite і git diff --check успішні. Браузер перевірив
уроки, практику, читання, словник, прогрес, спільні тренування й налаштування
вимови на desktop та 390 CSS px: заголовки відповідно 32/28 px, горизонтального
переповнення сторінки немає. Перевірені також навчальний крок із поясненням,
читання A2 й мобільна навігація. Під час вузької перевірки 312 CSS px знайдено
й виправлено накладання пунктів меню. На робочому frontend підтверджено
фактичне завантаження Inter та розміри 32/18/14 для заголовка/картки/опису.

Сесії для перевірки уроку й читання створювалися лише на ізольованій копії
PostgreSQL із власним тимчасовим API. Робочий профіль і прогрес не змінювались.
Тимчасові API, Vite та PostgreSQL зупинені після перевірки.
[Вимірювання браузера](typography-qa-20261018.json).

Нові компоненти мають використовувати існуючу роль, а не додавати власні px,
rem чи vw без потреби. Новий контекст, наприклад ігрова клітинка, може мати
окрему семантичну роль; однакові назви карток у різних розділах — спільну.
